### Contagem de objetos vivos — fonte canônica fixada

Divergência aparente contra o inventário da sessão anterior (11 triggers, 475
constraints) foi **resolvida como metodologia de consulta, não drift**:
`information_schema.triggers` conta uma linha por evento (5 triggers são
`insert or update`, 6 + 5 = 11) e `information_schema.table_constraints` inclui
253 pseudo-constraints de `NOT NULL` (222 + 253 = 475).

**`pg_trigger` e `pg_constraint` ficam como fonte canônica de contagem.** Query
usada, registrada conforme §15:

```sql
select
  (select count(*) from pg_trigger t
     join pg_class c on c.oid = t.tgrelid
     join pg_namespace n on n.oid = c.relnamespace
    where n.nspname in ('public','safa_private') and not t.tgisinternal) as triggers,
  (select count(*) from pg_constraint c
     join pg_namespace n on n.oid = c.connamespace
    where n.nspname in ('public','safa_private')) as constraints;
```

Resultado: 6 triggers, 222 constraints — idêntico ao inventário anterior.
Confirmados também 7 funções, 4 views, 28 políticas, 93 índices, 518 grants,
28 tabelas.
